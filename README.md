# Fogón — React + Supabase

Plataforma multiempresa para negocios de comida. Ver la guía completa
paso a paso en la conversación con Claude; resumen rápido:

```bash
npm install
cp .env.example .env.local   # y pega tus datos de Supabase
npm run dev
```

El esquema de base de datos está en `supabase/schema.sql` — pégalo en
el SQL Editor de tu proyecto de Supabase antes de correr la app.
